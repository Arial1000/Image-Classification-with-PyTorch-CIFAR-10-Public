# Kali Ferguson – Machine Learning & Data Science Projects

This repository explores hands-on experience in machine learning, deep learning, and data engineering. I strengthened my ability to design, implement, and evaluate models on real-world datasets using Python and PyTorch.

---

## Projects

### 1. CIFAR-10 Image Classification
- **Description:** Developed a neural network to classify images into 10 object categories from the CIFAR-10 dataset.  
- **Key Highlights:**  
  - Implemented in **PyTorch** with **torchvision**.  
  - Trained and evaluated using **cross-entropy loss**.  
  - Performance assessed with **accuracy, precision, recall, and F1-score**.  
  - Explored feature visualization and optimization techniques to improve model performance.  
- **Skills Demonstrated:** Deep learning, model evaluation, data preprocessing, PyTorch.

### 2. Fashion-MNIST Classifier
- **Description:** Built a convolutional neural network to classify clothing items from the Fashion-MNIST dataset.  
- **Key Highlights:**  
  - Focused on improving generalization and reducing overfitting.  
  - Evaluated model using standard metrics and visualized misclassifications.  
- **Skills Demonstrated:** CNN architecture, model tuning, and visualization.
